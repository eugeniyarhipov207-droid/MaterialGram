# MaterialGram

Material You-inspired Telegram client for Android.

🚧 **Work in Progress**

## Current features
- Telegram account authorization and login screen.
- TDLib integration.
- Material Design-inspired interface.

## Not implemented yet
- Chat list screen.
- Private and group conversations.
- Message sending and receiving.
- Media sharing.

**Note:** This is an early development build. Currently, only the login and authorization flow is implemented. The actual chat interface is not available yet.

More features coming soon!
